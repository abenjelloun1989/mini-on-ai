Step 1 — Add your Anthropic key

F1 needs your Anthropic API key to proxy your calls. Paste it in the dashboard (Settings tab), or send it via the API:

# Set your Anthropic key once
curl -X POST {{PROXY_URL}}/api/set-anthropic-key \
  -H "Content-Type: application/json" \
  -d '{"token":"{{DASHBOARD_URL_TOKEN}}","anthropicKey":"sk-ant-..."}'

Step 2 — One-line SDK change

Point your Anthropic SDK at F1. Nothing else changes — same models, same responses.

Python

import anthropic

client = anthropic.Anthropic(
  base_url="{{PROXY_URL}}",
  api_key="{{API_KEY}}", # your F1 key
)

Node / TypeScript

import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
  baseURL: "{{PROXY_URL}}",
  apiKey: "{{API_KEY}}",
});

What happens now

Every call you make through F1 appears in your dashboard within seconds: token counts, USD cost, model mix, latency, and status code. No prompt text is stored — ever.

The Insights tab shows rule-based recommendations (cache candidates, model-switch savings, batchable prompts) once you have a few calls in.
